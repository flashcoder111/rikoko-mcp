## Source-installer release scope (2026-10-21)

`THIRD_PARTY_LICENSES.txt` retains the installed production npm/Python package license texts, including the IBM Plex Sans font OFL text. `pnpm exec tsx scripts/verify-licenses.ts` verifies these notices and the exact font/artwork/preview hashes in `docs/integrations/media-licenses.json`; it emits `artifacts/license-review/dependency-licenses.json` (or the release run's `licenses/` directory). The previous abbreviated code manifest is not a complete dependency inventory.

The Python lock includes **mutagen (GPL-2.0-or-later)** through yt-dlp's default extras, **certifi (MPL-2.0)**, and **yt-dlp-ejs (Unlicense AND MIT AND ISC)**. Pillow 11.3.0 declares **MIT-CMU** in its installed metadata; its wheel may also contain separately licensed native libraries. These are not all covered by yt-dlp's Unlicense or rikoko's Apache license.

This acceptance scope is the **source archive plus installer**, not an offline dependency bundle or container image. The source archive excludes `node_modules`, `.venv`, system executables, downloaded models, user data and development reference videos. Dependencies and FFmpeg are downloaded to the user's machine from their upstream registries/package manager. Redistributing a populated runtime, image, FFmpeg/libx264 build, curl_cffi/Pillow native libraries or PGlite's PostgreSQL binary requires a separate bundled-library and corresponding-source review; this source review does not approve those products.

All bundled starter PNG artwork is generated by the checked-in deterministic Pillow script. All nine preview MP4s are regenerated locally from those drawings and bundled Noto Sans SC, without audio or model calls. The script now requires the bundled OFL font instead of selecting macOS proprietary fonts. Noto font bytes remain unmodified, with original license texts and hash provenance retained. User-imported/downloaded media are not included in the release and require their own rights confirmation.
