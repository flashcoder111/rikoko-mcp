# rikoko 核心功能验收 · 2026-10-15

## 结论与范围

核心创作链路已通过真实运行验收：参考视频分析、提取分镜、参考图片编辑、视觉审阅、MiniMax 图生视频、素材入库、工作台与对话修改、渲染，以及原对话视频/字幕/封面返回。本轮使用实际官方云端和 fal，不以模拟响应代替真实供应商结果。无需更换上游供应商或补充服务器权限。

用户明确将支付交付、安装升级留到后续；这些商业和分发流程不属于本次验收。这里的“原对话返回文件”仅指创作功能。结论覆盖下表实际用例，不代表所有题材、人物一致性、语言或可选插件均已验收。

## 本轮发现并修复的问题

1. 官方模式原来没有参考分析上传、任务路由和报告回传通路。新增 `reference_analyze` 官方桥接、云端分析 worker、JSON 结果取回与本地素材来源映射。供应商可用性列表同步修正。
2. 分析适配器覆盖了普通 fal 模型路径，导致混合目录不兼容。非分析任务现在交给已有 fal 生成实现。
3. 第一次真实分析被上游拒绝：`Reasoning is mandatory for this endpoint and cannot be disabled.` 已开启该端点要求的 reasoning；没有更换模型或隐藏重试。
4. 第二次分析返回有效内容，但末尾 7800 ms 超过视频实测 7500 ms，被本地严格校验拒绝。已把实测源时长、音轨状态和允许时间范围传给上游，第三次成功。没有篡改上游时间点，也没有放宽来源/越界校验。
5. 自然语言规划器把“文案是：”带进字幕。修复明确文案前缀解析，覆盖“文案是”“文案为”“字幕内容为”三类实际输入。

所有修改均先复现失败测试，再修复通过。真实失败任务保留可追溯记录，未伪装为成功。

## 模型质量边界与未验收项

- 参考片真实切镜在 2000 ms、4500 ms；成功报告估计为 1600 ms、4500 ms，首切偏差 400 ms。FFmpeg 同时保留独立测量切点 2042 ms。当前分析可用于结构理解和分镜草稿，不可承诺逐帧精准剪辑。
- 模型把末段概括为“360 度旋转”，实际短片不足以证明完整 360 度覆盖；运动方向、角度和机位描述仍需人工核对。不能把本样例当作严格动作还原质量达标。
- 本轮图片对照使用已有生成的产品图，验证了该图的再编辑一致性；没有验证真实商品照片的严格工业尺寸、人物身份或多角色一致性。最初从插画生成实物时曾改变瓶身细节，前一轮报告已记录。
- WhisperX 逐字转写及词级对齐需要独立本地环境和权重，本轮未安装、未完成真实语音用例验收。字幕编辑和 SRT 导出已验收，不等同于自动语音转写。
- Studio 内置对话规划器当前为 `local-commands`；复杂参考创作由宿主 Agent 编排本轮工具链。不能据此声称 Studio 自身已有独立通用创作模型。
- 原生 MiniMax/Gemini 直连接口按用户计划后续接入；当前调用经 fal。OAuth、自动人脸追踪、社交发布是能力列表明确未实现的功能。
