# TikTok 本地素材下载验收（2026-10-16）

## 行为

- 复用 `asset_import_url`，MCP 工具数量不变。媒体直链继续直接返回素材；TikTok 视频页面、vm/vt/t 分享链接进入已有本地 Worker，立即返回 job。
- 安装器通过 `python/uv.lock` 准备 `yt-dlp==2026.8.19`、`curl-cffi==0.16.0` 及传递依赖。首次使用缺少或变更的下载依赖时自动 `uv sync --frozen`，按完整锁文件哈希记录已准备版本。复用已有 Python、FFmpeg 和 ffprobe；用户无需源码或自行执行下载器命令。
- 环境准备、下载和校验均返回中文进度。`record_get(type=job)` 查询，`job_cancel` 取消；成功输出 `assetId`、媒体属性及 `outputs[0]`，后续继续现有分析流程。
- 下载为零模型费用任务，沿用账户权限、幂等提交、持久化状态和失败恢复。独立付费分析仍须原有报价确认；只分析请求不会因此生成、创建项目或渲染。
- 公网地址、重定向与 CDN 连接均经进程内临时回环代理校验并固定目标 IP。私网、链路本地、混合 DNS、非 Web 端口均拒绝。默认复用标准代理环境和 macOS 系统网页代理；可用 `RIKOKO_DOWNLOAD_PROXY` 覆盖。
- 兼容本地代理的 198.18/15 合成 DNS：经所选代理向固定 Cloudflare HTTPS DNS 解析真实公网地址，校验后固定连接；不直接放行合成地址。请求只包含待解析域名。
- 最终文件上限 100 MiB，临时总占用上限 300 MiB；下载进程限时三分钟，环境准备限时五分钟。取消中止下载进程组；共享依赖安装可以安全完成，不阻塞该下载任务的取消。临时目录结束时清理。
- 不加载用户 yt-dlp 配置、插件或浏览器 Cookie；不自动更新和下载远程组件。下载进程不继承供应商 Key；返回错误隐藏原始 stderr 中可能出现的签名媒体 URL。
- 本机监听、本地数据库和本地素材库存储的运行时启用此入口；对外监听、远程数据库和 S3 存储运行时默认关闭，并在执行前复查。
