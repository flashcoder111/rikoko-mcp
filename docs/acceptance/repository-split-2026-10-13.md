## 源码与依赖

官网、官方云端入口、R2 管理、云端部署配置及对应测试移到平台。MCP 保留本地服务、Studio、工作队列、媒体执行与云服务客户端。两套代码各自安装、构建、测试和 Git 提交。

平台通过 `vendor/rikoko-0.1.1.tgz` 引用公共运行时，锁文件记录依赖完整性，发行清单另外记录 SHA-256。平台不导入兄弟目录源码；网站参考导入器的 happy-dom 依赖已明确声明，原 npm 锁文件保留在忽略的迁移归档中，网站与云端统一使用平台 pnpm 锁文件。

运行时包包含数据库迁移、媒体 JSON schema、Python 源码和工作台构建。打包程序拒绝不同内容覆盖同版本文件，也检查必需资源及私有路径。跨端浏览器验收在平台 `.cache/` 建立独立 Python 环境，避免借用 MCP 的虚拟环境。
