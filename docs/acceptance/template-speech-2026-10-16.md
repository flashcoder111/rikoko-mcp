# 口播模板按需对齐 · 2026-10-16

## 实现范围

- 商品卖点、三步教程、三点清单、软件功能介绍、用户评价模板声明可选口播能力；默认准备保留原时长，不触发转写或配音。
- `template_prepare.speech` 接受最终音频／有声视频及其源素材绑定的转写，复用现有画面，以实际词组边界编排镜头。
- 模板页提供可选口播与对应转写选择；仅列出所选录音对应的转写。准备不购买模型调用。
- 默认句级字幕：工作台、视频烧录与 SRT 使用首词至末词的实际时间。
- 模板可用 `speech.anchors` 声明关键词与出现次数，绑定已有叠加事件；不复用另一份转写的词 ID。
- 配音替换使旧对齐与依赖词的事件失效，音量调整保留对齐；裁剪、分割、变速同步映射，静音区间不显示口播字幕。
- 独立标点不重复参与切镜；中文粗粒度词组不平均分时。用户视频及云模板默认视频短于旁白时，准备阶段明确报错。
- 内容相同但来自不同录音的转写分别保存来源；同一录音的相同转写仍可复用。

接口与模板规则示例见 [声音流程](../speech.md#口播模板按需对齐)。

## 发布状态与边界

本轮沿用 `main`，保留开始时已有的未提交改动。仅本地修改和验证，未提交、推送或部署，也未重启当前已连接的 MCP。没有真实供应商转写、配音或付费调用；测试中的词时间明确为预计算测试数据，真实 FFmpeg 导出不代表真实 ASR 精度或听感验收。

本轮未新增逐字高亮、嘴型同步或强制对齐供应商。换配音需要取得新录音对应的转写并重新编排，系统不会自动购买转写或重新配音。
