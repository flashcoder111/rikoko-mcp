# 一行安装与默认官方 API 接入验收

日期：2026-10-12。状态：本地实现与隔离安装验收完成；正式域名、公开分发、真实官方用户 Key 联调尚未完成。

## 已实现

- 运营侧通过 `pnpm release:installer`，从公开发行清单生成源码压缩包、SHA-256 和单行命令使用的 `install.sh`。默认内置官方 API 与独立模板源；拒绝示例域名，不创建 Git 仓库/分支，不上传或部署。
- 安装器下载校验、拒绝不安全归档路径与链接、准备 Node/uv/Python/FFmpeg 和锁文件依赖；同版本可重跑，保留用户 config、凭据和宿主其他 MCP 配置。
- 官方账户使用每位用户自己的 Key。交互输入不回显；只向官方网关请求用量验证，拒绝重定向，不向模板服务发送 Key。无 Key 时保留官方模式并明确提示未绑定，本地编辑不受影响。
- 安装版 MCP 自动启动本地后端。服务先绑定专用回环端口，再打开数据库；多个 MCP 进程竞争时仅一个后端进入数据库。通过安装实例 ID 验证服务，端口不匹配时不发送凭据。
- 私有 config 文件权限 0600；MCP 配置只含本地凭据文件路径。启动后端时只读取当前模型配置引用的 Key，隔离宿主遗留的供应商、数据库和 Node 注入环境。
- 安装末尾运行真实 MCP 连接检查与免费 FFmpeg 样片。提供不依赖全局 Node PATH 的 `service` 启动/停止/重启命令。

## 尚待完成

- 实际下载域名、官方 API 与模板域名仍未提供，当前只有配置示例，没有可公开执行的真实安装链接。
- 官方账户仍是用户 Key 绑定；没有新增注册、网页登录或设备授权。支付及充值流程保持原有待办。
- 本轮 macOS 验证复用了已安装的 Node、uv、FFmpeg 和依赖缓存；尚未在完全无依赖的新机器上实测 Node/uv/FFmpeg 引导下载及系统权限提示，也未做 Linux/WSL 或原生 Windows 验收。

- 不同版本的自动升级迁移未纳入这次安装流程；当前拒绝覆盖不同版本的安装目录。
