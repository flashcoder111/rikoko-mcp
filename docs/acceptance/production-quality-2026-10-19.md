# 通用生产质量能力：2026-10-19

实施阶段：本地源码实现与验证，保留仓库中此前已有的其他改动。后续经用户授权，0.1.24 已部署并同步 Hermes，见[上线验收记录](production-quality-release-2026-10-19.md)。本文件下方记录实施阶段的设计与测试边界。

## 起因与设计边界

本次排查暴露的不是单条提示词缺少形容词，而是规划、输入、剪辑与验收之间缺乏可追踪的约束：支撑物和工序起始状态矛盾；已完成步骤被重复；短镜头承载多个独立动作；片段各自生成音乐而没有整片配乐安排；收尾未定义产品与品牌的关系；泛化的“通过”缺少对应动作证据。

因此，把导演方法放在 Skill，把可确定验证的结构和证据绑定放在 MCP。MCP 不推断真实物理、不自动听出节拍，也不替宿主宣布画面漂亮或广告有效。一次失败不能证明模型的能力上限；模型比较仍需固定输入和规格、控制变量、多次采样，并单独批准费用。

## 能力与入口

| 能力 | Skill 中的工作方法 | MCP 中的执行约束 |
| --- | --- | --- |
| 工序状态 | 对象身份、数量、支撑、遮挡、已完成步骤；跨镜头检查；有理由的时间跳跃 | `plan.process` 对象登记；`shot.process` 完整状态、前置条件和效果；检查未知对象、支撑关系、状态重置和连续性 |
| 动作安排 | 一个主要可读变化，准备→接触→完成→停留；必要时拆分 | 操作阶段有界、有序；依赖对象操作不能重叠；起始状态图必须是真实的首帧引用；边界图提示词只描述静态状态 |
| 音乐卡点 | 先选择整片音频策略，再以实际试听/测量建立音频线索；保留动作完整性 | `plan.editing.audio` 绑定音频 ID 与 SHA-256、增益及混音策略；节拍来源说明；镜头事件偏移与音频线索误差检查 |
| 广告收尾 | 明确展示结果、产品与品牌关系、可读停留和声音结束；CTA 按事实选用 | `plan.editing.ending` 声明末尾镜头、产品可见性、品牌/CTA、最低停留；检查实际结尾位置、时长和媒体类型 |
| 逐项验收 | 检查每个动作与状态；真实试听整片；重新剪辑后重验 | 自动生成质量义务；源片绑定项目/作用域/镜头；成片绑定 revision 和作用域 hash；缺失、失败、未知阻止验收 |

新增 `production_editing_preview {planId, expectedVersion, revisionId?}`：返回计划或实际剪辑时间线、卡点误差、问题和验收项。该工具只读，不生成、不剪辑、不收取生成费用。

`production_shot_prompts` 将工序和剪辑意图编入提示词，并返回当前镜头质量验收项。增强提示词使用 `rikoko-direction-v3`；旧计划保留 v2。超长提示词报错要求简化/拆分，不截断约束。

宿主使用 `capabilities.productionQuality` 发现能力，通过 `rikoko_guide topic=production-quality` 读取指南。完整字段与例子见 [production-quality.md](../../skills/rikoko/references/production-quality.md)；验收字段见 [visual-review.md](../../skills/rikoko/references/visual-review.md)。

## 验收不能绕过的要求

- 每个计划工序分别检查状态、动作及稳定结果。通过的动作区间本身需要至少三个不同采样点，覆盖首中尾且间隔不大于 250 ms；停留段样本不能补足动作证据。局部缺陷仍允许用少量样本记录失败。
- 已验收的动作和停留区间参与最终裁切保护。后来的通用验收不能遮蔽当前工序验收；后来的失败或未知仍会撤销此前通过。
- 音乐连续性、卡点、声音结束必须由宿主或用户实际试听当前完整输出后记录。波形、截图和数值能支持分析，但不能冒充听感通过。
- 最终增强验收使用 `workspace_validate.productionScopeHash` 作为 `media_review.expectedProductionScopeHash`。计划变化后，旧范围和旧判断不能自动成为新要求的验收。
- 本地计划更新、项目计划重绑、云端计划同步及云端作用域重绑均保留已经声明的质量契约。可以修改内容并重新验收，不能删除契约来规避检查。

## 兼容性与限制

- `process`、`editing` 是可选扩展，旧计划继续工作。宿主根据任务声明相关能力；本次不把所有旧工程强制转换为工序片或广告。
- 支撑和关系检查针对已声明的状态一致性。例如，“某对象可以支撑另一个对象”是否符合真实材质、尺寸和用途，仍需要导演判断与实际画面复核。
- 对象被遮挡或离开画面可以用 `occluded` 表示；不等于对象消失。产品照片不自动等于工序首帧。纯文本状态锚点允许使用，但明确提示更强状态参考的价值。
- 当前整片共享音频从源文件零点播放。使用其他区间时须先准备独立音频片段、导入并绑定新 hash，再以新零点建立卡点；本次没有增加自动 BPM 检测或音频剪辑器。
- 声音结束方式记录创作意图和验收义务，不自动执行淡出或保证乐句已经结束。必须在实际渲染中完成并试听。
- 产品可见性/品牌可读性同时有结构检查和人工视觉判断；有媒体文件不能证明里面确实是正确产品。
- 本地测试与模拟 provider 不证明真实 MiniMax 输出质量。部署后仍需重连 MCP 并对实际输出进行受控验收。
