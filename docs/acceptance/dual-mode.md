## 实际贯通流程

本地服务 `http://127.0.0.1:4310`，作品 `fcb26029-46d0-46d4-bf5e-63dd9fc7bcd7`：

1. 在浏览器对话输入三段脚本，确认方案，FFmpeg 生成 6 秒竖屏成片 v1。
2. 打开同一作品工作台，修改第二镜头字幕，生成 v2；其他镜头保留。
3. 返回对话输入“删除最后一个镜头，字幕大一点”，生成两个镜头、4 秒、32px 字幕的 v3。
4. 播放 v3，实际 currentTime 从 0.23 秒推进到 4 秒，ended=true；视频 readyState=4。
5. 390×844 手机视口进入版本面板，恢复 v2 为新 v4（3 镜头、6 秒），v1–v3 全保留；返回对话显示当前 v4。
6. 刷新及服务重启后会话/作品/任务可继续；桌面 1280px、手机 390px 页面 scrollWidth 等于视口宽度。
7. 官方 MCP v2 客户端连接正在运行的服务，读取同一个 v4，取得真实 MP4/字幕/预览图。检查媒体响应、文件摘要、MCP Apps 资源 MIME 与工具 UI 元数据；查询前后任务数都为 4。验收发出的媒体权限随后撤销。

证据：`artifacts/dual-mode/protocol-verification.json`、`result.mp4`、`desktop-studio.png`、`mobile-studio.png`、`mobile-chat.png`。视频是明确标记的本地原创图形/文字卡片，属于 local-real 合成，不是 AI 生成镜头。一次内置浏览器预览页崩溃后换新预览页恢复；重新播放成功，作品未丢失。此过程不替代真机浏览器测试。

## 当前能力边界

外部 Agent 可以自行理解要求并通过同一套 MCP 完成创建/编辑/交付，不需要服务端另开创作模型。网页默认支持明确编辑命令、已有素材编排和脚本卡片；可选创作模型适配已经接好但未启用。自由生成画面、真实转录、译配等沿用已有独立适配器与各自外部验收状态。

Hermes/ChatGPT/Claude 等真实宿主的富卡片显示、平台附件、原生媒体发送仍未实测；已验收的是官方 SDK 协议和本地浏览器。OAuth/手机公众账户接入、远程可达域名、生产环境、自动静音删减、人物跟踪和跨付费工作流总预算也没有被当作本轮已完成项目。

本轮真实付费调用为 0。仅打开两个界面或取回成片不新增生成任务；修改后重新本地合成，复用原素材。没有通过降低覆盖率门槛或将 skipped 记为 passed 来通过验收。
