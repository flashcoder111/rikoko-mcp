## 使用体验

- 新模板放在目录前方并标注“新增”，卡片显示用途、镜头数、时长和画幅。
- 支持 App、SaaS、改造、口碑等关键词，英文搜索不区分大小写；可清除筛选，加载和无结果状态有提示。
- 每套新增模板提供素材准备说明，成片示例默认展开，分镜显示各镜头实际插画。
- 点击“修改文案与画面”可直接进入输入框。编辑文案时自动定位对应分镜、收起并暂停默认示例；字数上限可见。
- 修改字幕复用已有素材，模板准备不创建生成任务。最终预览由本地 FFmpeg 合成。

这轮没有测量宿主 Agent 的 token 节省比例。模板复用减少了从头组织分镜和生成画面的需要；模板目录本身仍会占用 Agent 上下文。

## 内容来源与后续开源模板适配

本批分镜、PNG 插画和参数定义为项目内新增内容，由 `scripts/build-starter-art.py` 绘制，沿用项目 Apache-2.0 许可。没有复制第三方模板源码、图片或视频，没有加入新的渲染引擎。插画包含“示意画面”标注，可换成用户素材。

此前调研的开源目录仍可作为后续适配来源，例如 [SwiftClip](https://github.com/zz41354899/SwiftClip) 和 [Content-Agent-Kit 的 video-templates](https://github.com/XuHo-IT/Content-Agent-Kit/tree/main/video-templates)。本批优先让现有运行时具备可预览、可改文案、可换素材的完整流程；这些开源目录尚未导入。后续每批只选少量适合当前用户用途的模板，连同示例、参数和来源说明一起适配。
