# 开源边界与统一 API 计费优化验收

日期：2026-10-12。状态：本地修改、构建及隔离验收完成；尚未对外发布、部署或接通在线支付。

## 本轮完成

- 模板源与生成网关独立配置：`TEMPLATE_API_URL` 不改变自有供应商接入；`GENERATION_API_URL` / `GENERATION_API_KEY` 只负责官方生成。config 支持独立 `templates.url` 和 `templates=false`。旧环境变量保留兼容。
- 生成 Key 只发往生成 origin。缺少官方 Key 时明确失败，不自动改用用户的个人供应商账户。模板仍由用户手动更新，已有项目保留快照，本地编辑/渲染不消耗官方额度。
- 用户售价、实际扣款与供应商成本分开。成功按固定报价快照结算；供应商成本未知时可独立核对，重复核对不会重复扣款。失败/取消的固定售价任务核对后释放用户预留，供应商已发生费用单独记录。旧成本结算模式保留。
- 公开模型、报价和任务接口返回用户价格；供应商上限、实收与核对备注留在运营侧。新增管理员成本核对端点、最近 100 次 API 调用摘要及桌面/手机账单展示。
- `pnpm export:public` 根据明确清单导出本地应用、MCP、媒体处理、模板协议/客户端和自有模型适配器。排除官方云后台、真实配置、运行数据、研究内容和开发样片；拒绝符号链接与已有输出目录，生成 SHA-256 清单。
- 保留现有 fal/Replicate、图片/视频/音频、套餐目录及编辑器改动；没有改写根许可证或创建 Git 分支。
