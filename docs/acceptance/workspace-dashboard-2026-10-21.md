# 工作空间 Dashboard

默认首页 `/` 和未指定项目的 `/workspace` 现在显示工作空间概览。`/workspace?project=…` 继续进入编辑器；旧的 `/?project=…`、`/?request=…` 对话链接保持兼容，新对话入口为 `/chat`。

## 参考与实现

核对 Hypit 远端 HEAD `0d36de9a9d17562fca0e478969b80eb1c16a7693` 的 [Studio README](https://github.com/hypit-ai/hypit/blob/0d36de9a9d17562fca0e478969b80eb1c16a7693/packages/studio/README.md)。参考其 Tasks、Artifacts 分离、任务筛选及错误展示的组织方式；本次未运行 Hypit 的 Studio，也未复制其实现。

rikoko 首页提供项目搜索、任务状态筛选、错误详情、任务输出预览下载，以及工作空间连接与模型服务概览。原有编辑器、素材库、对话和服务用量入口保留。只把任务 outputs 中已有的图片、视频和音频列为媒体输出，不把上传素材冒充生成结果，也不把任务完成等同于画面通过验收。

数据来自现有账户范围内的 records_list 与 capabilities。页面可见时每 10 秒刷新本地记录，支持手动刷新；刷新失败保留上次数据并显示错误。断开连接会清空数据并丢弃尚未完成的旧请求。统计不包含本地尚未同步的远端任务状态；页面不会提交、重试或取消生成任务。
