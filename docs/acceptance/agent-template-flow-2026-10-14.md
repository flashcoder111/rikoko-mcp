# Agent 自动使用模板与素材

2026-10-14。按用户纠正，将模板库转为 Agent 的内部创作资源。用户直接描述想法；没有参考视频也可开始，不进入模板选择、填表、逐镜头选素材的流程。

## 实现

- 首页移除成片模板导航、模板选择卡片和素材选择引导。旧 `/templates` 链接显示对话入口。素材库保留为可选管理工具。
- `template_match` 按用户描述只读检索内置/已缓存的云模板与当前账户相关素材。结果供调用 Agent 判断，不要求用户选择；需要更广语义判断时可读取完整目录。
- MCP 指令明确自动选择和改写、优先用户参考与已确认素材、尊重“不用模板”、仅对确实缺少的新媒体走原有报价。
- 网页 `workspace_plan` 接入同一资源。启用创作模型时，模型取得候选结构、参数、镜头和相关素材元数据，返回一个经过校验的选择和文案。常见用途也支持无模型的本地匹配与原文编排。
- 只导入用到的现成素材，返回可执行 composition；普通创作请求由网页直接提交预览。用户只要方案时仍可查看方案，不自动创建作品。修改已有作品沿用原有编辑路径，不重选模板或生成画面。
- 素材归属、模板版本、文案参数和时长经过验证；不按“商品”等宽泛分类把无关素材插入作品，不把模板示例评价或默认占位文案当成用户事实。
