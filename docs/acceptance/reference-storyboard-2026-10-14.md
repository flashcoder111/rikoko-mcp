# 参考图驱动生成：本地验收（2026-10-14）

## 已实现

参考视频分析 v2 → 本地抽取构图帧和可选动作片段 → 目标人物、产品、场景与风格的多参考图编辑 → 实际视觉审阅记录 → 已审阅图驱动的视频生成 → reference_adapt 回填 → 现有本地渲染。

- MCP 新增 `reference_storyboard_prepare`、`reference_storyboard_review`、`reference_storyboard_quote`，并可通过 `record_get` / `records_list` 读取分镜记录。宿主指引说明图生图顺序、真实审阅要求、MiniMax 偏好、复用和报价流程。
- `generate` 新增角色化参考素材和模式契约。fal / Replicate 接收服务器解析后的参考字段；客户端只提交当前账户素材 ID。MiniMax 首帧、首尾帧、多参考接口的字段映射见独立示例配置。
- 报价绑定素材、模式、输入顺序、模型档案与分镜版本。已通过图片复用；改变审阅或引用内容使旧请求失效。视频档案短于目标镜头时明确拒绝。
- Worker 在执行前校验引用内容，在素材准备后、供应商提交前再检查审阅和取消状态。无效 URL、字段碰撞、类型或数量不符、越权引用、超限素材在调用前拒绝。
- 本地抽帧和裁切使用真实 FFmpeg，记录源素材哈希和请求时间；不标榜逐帧精确分析或自动最佳帧选择。

## 实测边界

供应商任务、分析报告和生成结果由测试夹具提供；本地 FFmpeg 抽帧、裁切、探测与渲染实际执行。未发起真实付费生成，不证明供应商账号已接通、人物一致性或产品细节还原度。

没有部署、推送或重启已有服务，没有启用费用占位配置。变更在原有 main 分支上完成；没有创建分支。保留原有模板、素材库、工作台等并行改动。

官方参考素材上传与计费协议仍需在 rikoko-platform 接入，当前明确返回不支持，不切换到个人供应商。没有新增 Studio 分镜审阅页面；编排和审阅记录由原宿主 MCP 会话完成。底层支持首尾帧和视频输入契约，但分镜工具当前只自动编排图生图和首帧/多参考生视频。
