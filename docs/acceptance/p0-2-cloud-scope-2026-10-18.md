# P0-2：云端准备合同和正式制作范围

日期：2026-10-18。状态：两个仓库的本地实现及合同测试；没有提交、推送、部署、重启宿主或付费生成。沿用现有 `main`，保留原有修改。宿主 Agent 继续负责规划、编排和视觉判断。

## 云端请求合同

- 增加 `rikoko-cloud-preparation-v1` 能力协商。旧服务或无法确认协议的连接返回 `PREPARATION_PROTOCOL_UNSUPPORTED`；不移除准备 ID，也不退回普通生成。
- `generation_prepare` 调用服务端模板和真实模型配置，保存服务端准备稿及本地映射。准备阶段只传素材 SHA-256、大小、类型和适用的媒体信息，不上传文件、不报价、不预留费用、不调用生成模型。
- 报价前上传实际素材，云端核对拥有权、文件哈希、大小和实际探测信息，创建不可变的绑定记录。其 `parentPreparation` 关联原准备稿；重试得到同一绑定记录。图片不会把无意义的零时长或音频字段当成图像约束。
- 本地与云端分别保留准备记录 ID/哈希。报价与任务公布模板版本、准备 ID/哈希；网关核对合同，轮询保留本地关联，provider 请求沿用冻结的提示词、参数及参考顺序。
- 本地计划和范围有单调版本的云端镜像。已绑定依赖更新时，先同步再保存；连接丢失或变为另一连接时明确拒绝修改。重复同步相同版本/内容可恢复，回滚版本或同版本改内容会拒绝。
- 云端在报价、提交、解析参考素材、发送 provider 前重验。排队期间计划/范围变更、素材变化或配置变化均不能悄悄沿用旧请求；发送前失败按未消费处理。已提交的同一幂等键仍返回原任务。

HTTP 路由均要求账户认证，写入要求 write/admin：

| 路由 | 用途 |
| --- | --- |
| `GET /v1/generation-protocol` | 协议支持及检查边界 |
| `POST /v1/production-context` | 单调版本计划/范围同步 |
| `POST /v1/generation-preparations` | 无上传的服务端准备稿 |
| `POST /v1/generation-preparations/:id/bind` | 验证已上传素材并生成冻结绑定 |
| `POST /v1/quotes`、`POST /v1/generations` | 原有入口，增加准备记录校验和返回元数据 |

rikoko-platform 使用 `vendor/rikoko-0.1.21.tgz` 和校验清单安装共享代码；未引入兄弟仓库依赖、源码复制或软链接。中间测试包未发布。

## 正式制作范围

新增 `production_scope_save`：项目持久保存计划 ID/版本、范围版本、必需检查项和允许的素材用途。首次使用 `expectedScopeVersion=0`，更新需要当前版本；没有单次请求关闭正式范围的字段。默认允许 `prepared_generation`，使用外部/实验素材必须显式允许 `external`。

正式生成输入使用 `production={projectId,scopeVersion,shotId}`，同时准备该范围对应的 `plan={planId,expectedVersion,shotId}`。引用正式范围而没有准备记录的报价/提交被拒绝。旧的通用试验生成保留兼容，但不会自动取得正式素材资格。

新增 `production_asset_assign`：先检查实际源素材并用 `media_review` 接受，再归属到项目、范围和目标镜头。`prepared_generation` 必须来自该范围/镜头的已完成准备任务；`external` 必须由范围允许。未知、未审核、旧字节和不匹配来源不能通过。

Composition 场景携带 `productionShotId`；现有场景可通过 `revision_revise` 的 scene patch 设置。目标计划默认 `visualKind=media`，真正的标题/品牌卡需在计划中声明 `graphic`，不能只在 composition 标成 graphic 来替代目标媒体。

`workspace_validate` 合并目标尺寸、镜头映射、目标镜头缺失、素材归属和当前源素材审核检查。成片审核记录绑定范围哈希；范围或计划变化使旧归属和成片接受失效。现有 `workspace_result(purpose="final")` 使用这些检查；草稿仍可保存、渲染和预览。

## 验收边界与下一步

本批补齐了云端合同和项目正式制作范围的实现，并以本地 HTTP 集成验证。线上运行时与各宿主安装尚未更新；实际 MiniMax 生成质量、真实镜头语义和跨宿主接图仍未验收，因此不宣称 P0-2 真实制作验收或 P0 全部完成。

P0-3 继续处理动作/台词完成锚点、剪辑入出点与更多导出/下载入口的一致约束。本批只保证已接入的 workspace 正式交付判定，不能把任意导出成功解释为正式质量通过。视觉判断仍来自宿主或用户，不由确定性校验代替。
