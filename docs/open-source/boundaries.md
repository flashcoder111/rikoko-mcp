# 本地开源与官方云服务边界

本地开源部分包括工作台、MCP、项目/素材/版本、渲染、模板格式、同步客户端及模型适配器。官方云服务仅提供模板更新分发和统一模型 API 收费。模板定义和素材分别标注权利来源。

用户作品与本地素材不为模板同步而上传。API 请求只提交模型所需输入，生成结果下载到本地。供应商结果地址可能过期；官方服务没有长期保存作品的承诺。

公共客户端公开服务协议与调用逻辑；官方发布后台、账户运营及供应商成本管理独立维护。客户端不能自行修改官方价格或余额。自带 Key 的调用由用户自己的供应商账户付费。

发行物使用明确文件清单，不包括官方云后台、真实配置、数据库、运行日志、研究资料或第三方开发样片。正式对外发布仍需核对实际复用代码及全部素材的许可，不能把文件排除检查视为完整权利审计。

对已有接口保留兼容：`HYPIT_CONFIG_FILE`、`HYPIT_*` 和 MCP 的 `hypit` 注册名暂不强制迁移。产品来源和第三方依赖按实际复用关系说明。

## 项目命名

项目名称统一为小写 `rikoko`，视频 MCP 的产品介绍、页面文案、教程和 Agent 对话均使用 `rikoko` 或 `rikoko MCP`，不再把本项目称为 Hypit。显示名称与包名已统一为 `rikoko`。已有 `HYPIT_*`、`VIDEOWORKBENCH_*` 环境变量、MCP 的 `hypit` 注册名和 prompt 名、Keychain 标识、浏览器存储键及安装目录/归档路径保留兼容，避免改名后丢失现有连接、凭据或草稿；提及这些标识时应明确其兼容用途。第三方参考来源和历史验收记录保持原名。
