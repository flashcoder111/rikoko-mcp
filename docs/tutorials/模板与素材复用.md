# 直接描述，Agent 自动选择模板和素材

用户不需要先选模板，也不需要为了开始创作而上传参考视频。模板库为 Agent 提供剪辑结构和可复用画面，素材分类帮助它找到已有内容。

## 用户流程

输入想法 → Agent 理解用途、内容和限制 → 自动检索并选择结构与素材 → 填入文案、调整比例和时长 → 本地合成预览 → 对话修改或工作台精修。

例如：

> 帮我做一条 15 秒的咖啡店新品宣传视频，主打生椰拿铁，温暖一点。

Agent 自动决定采用哪个结构，不给用户一排模板让用户挑选。相关已有素材优先复用；没有实拍素材时可以使用合适的图形插画，并如实说明。若要求真人口播、指定动作等现有素材无法满足的内容，应指出缺口并处理相应生成报价，不把插画说成实拍。

用户提供参考视频时，应优先遵循参考需求并按参考分析流程处理；用户明确“不用模板”时不套用模板。改字幕、调整节奏时保留已确认的画面。

## Agent 如何使用

- 宿主 Agent 调用 `template_match({brief})`，取得内部候选结构和相关账户素材；它自行判断和选择，不把候选列表转交给用户。该工具只读，不下载、不合成、不生成。
- 如需更全面的语义判断，`template_list` 返回全部内置和本地缓存的云端模板。
- `template_prepare` 接受文案参数、镜头与素材绑定；只导入实际用到的现成素材。Agent 可以继续调整返回的 composition，再用稳定幂等键调用 `workspace_commit` 本地合成。
- 网页对话通过 `workspace_plan` 自动走相同的模板与素材检索流程。配置了创作模型时，由模型选择模板和编写文案；服务验证模板版本、文案参数和素材归属后准备作品。匹配完成的模板作品直接创建预览，无需再选模板或点一次“应用”。
- 未配置网页创作模型时，本地规则支持常见用途的匹配和原文编排，不声称具备通用语义创作能力；不支持的描述仍需进一步处理。外部宿主 Agent 可自行完成创作，不要求额外配置网页模型。

## 素材归纳

素材库是可选的管理入口。按人物、商品、场景、背景、品牌、配乐、音效、成片等用途归类，配合名称、标签和收藏检索。自动匹配使用具体主题词，不会仅因同属“商品”分类就把无关图片插入作品。账户之间的素材隔离；同一素材按内容哈希复用，避免重复导入。

内置 9 个模板、15 张原创插画继续作为 Agent 的资源，包含商品、门店、教程、清单、活动、品牌、软件介绍、前后变化、用户评价。这是图形素材库，不是实拍人物或配音库；真实评价不能由占位文案充当。

## 费用和版本

本地检索与合成不调用付费图片或视频生成。宿主 Agent、已启用的网页创作模型以及新增媒体生成的服务费用分别计算；新增媒体沿用报价确认流程。

云模板只在用户要求更新并调用 `template_sync` 时同步，已有作品不会随目录更新改变。每次修改保存版本，画面可以反复复用。
