# Image direction

State the desired image, camera distance, setting, light and the visible initial state. Product references control factual details; style references control appearance. Do not replace product geometry or logos with those of a composition reference.

For an action shot, make the first frame a plausible state before the operation. A closed object cannot simultaneously expose hidden components without a visible opening or an explained cut. A final beauty image is usually a separate shot from the preparation image.

Generate in the intended output aspect. Leave space for hands, moving parts and captions. Examine identity, text, product shape, object count, contact points and edge clearance with `media_inspect`. A large crop can remove the very action the shot is meant to show.

When using first/last-frame video, both images need matching aspect and compatible identity, scene geometry and lighting. Inspect and accept the ending image through `media_review` before including it as a last-frame reference in the prepared video input. The start image keeps its storyboard review requirement.

Use `generation_prompt_preview` for the exact image request. Keep target instructions concise; the complete analysis and state plan remain available as host evidence. A successful image job is still unreviewed.
