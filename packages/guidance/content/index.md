# Director knowledge

Use three complementary layers in order: **content format → directing craft → model writing**. Formats organize a whole work; craft explains transferable production decisions; model writing expresses those decisions for the actual model and input mode. Host adapters, tool usage, permissions and memory are supporting documentation.

Read the catalog returned with this guide. Follow only relevant entries; an unfamiliar format can use craft directly. Optional `selection={format,crafts,modelId,mode}` returns a reading path. Persist format/craft selections as `plan.knowledge`; execution supplies the actual model and mode. Selection is a reading aid, not a compulsory template or permission to generate.

- `rikoko_guide {topic:"formats/index"}`: whole-work formats and their craft links.
- `rikoko_guide {topic:"craft/index"}`: transferable direction, reference, image, sound, editing and review methods.
- `rikoko_guide {topic:"models/index"}`: model-writing scope and available adapter guidance.
- `rikoko_guide {topic:"overview"}`: director responsibility and the production workflow.

Each catalog entry identifies its layer, related topics, source status and any exact model/input-mode scope. The returned navigation is generated from the same versioned catalog as the tool schema and file paths. Legacy topic names remain aliases to those files.

The first sourced expansion covers talking-head/UGC and product advertising, presenter performance and product staging, and Seedance 2.0 Mini / MiniMax H3 writing. Follow the catalog to the actual pages. Source labels distinguish existing guidance, official documentation, external examples and rikoko trials. Official-source entries may include clearly identified authored applications; the label describes provenance, not measured success. External knowledge can be adopted with attribution and limitations without first commissioning a paid reproduction. Private task evidence and user preferences remain separate from published knowledge.
