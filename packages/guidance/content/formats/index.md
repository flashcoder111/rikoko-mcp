# Content formats

Format guides describe how a type of work is organized: audience intent, structure, roles of references, and what makes the whole work succeed. They link to craft instead of repeating universal technique, and to model writing only through the actual execution context.

Available formats are UGC advertising, talking-head advertising, product advertising, and physical-process B-roll. Talking-head guidance also applies to non-ad explanations when the sales structure is unnecessary. See the returned catalog for canonical topics. Dialogue/podcast and other formats have not yet been added; do not imply that an empty category contains a playbook. Use applicable craft when no format fits, and keep format choices optional.

When adding a format later, register its title, existing content file, relevant craft links and evidence sources in the catalog. Include purpose, production choices, reference responsibilities, applicable limits and observable outcomes. Model-specific token syntax belongs in the model layer.
